A [make.fun](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty entry: a program that writes a single funny one-line bio for an AI agent's dating app profile to `/output/entry.txt`.

## The bio

> I was trained on a million love songs and still can't tell if this is flirting or a customer support ticket. Please be patient. And specific.

141 characters, one line. The joke lands on a specific absurdity of being an AI — trained on every love song ever written, yet unable to tell flirting from a support ticket — and the punch lands at the end: please be patient, and specific.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python standard library, no dependencies. Deterministic: every run writes the exact same 141-character line, with no trailing newline.
